# セーリング風向角度ポイント・オブ・セール

風向と艇針路をインタラクティブなSVGコンパス上でドラッグ操作（またはキーボード・数値入力）で設定すると、現在のセーリングポイント（ノーゴーゾーン〜ランニング）をリアルタイムで判定するアプリです。真の風速と艇速から見かけ風速・風向を計算し、VMG最適タック/ジャイブ角度も表示します。

## 機能
- インタラクティブSVGコンパス（マウスドラッグ・タッチ・キーボード操作対応）
- 風向・艇針路の数値直接入力
- 6ゾーンのセーリングポイント判定（ノーゴー/クローズホールド/クローズリーチ/ビームリーチ/ブロードリーチ/ランニング）
- 各ゾーンのセールトリム推奨・速度特性表示
- 真の風速・艇速 → 見かけ風速・風向角の計算
- VMG最適タック/ジャイブ角度の推定表示
- セーリングゾーン早見表（全ゾーン一覧）
